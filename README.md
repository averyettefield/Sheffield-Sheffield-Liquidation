# Sheffield & Sheffield Liquidation

A responsive website starter for Houston, Texas. Built with HTML, CSS, and vanilla JavaScript; no build tools required.

## Open in VS Code

Open this folder in VS Code. Open `index.html` in a browser, or install the VS Code Live Server extension and choose **Open with Live Server** on `index.html`.

- `index.html`: page content and navigation
- `styles.css`: colors, layouts, responsive styles, and original CSS illustrations
- `script.js`: mobile navigation and footer year
